# Dataset_to_streamli
# Dashboard Interactivo de Análisis de Datos

##  ¿Qué hace este proyecto?
Esta aplicación web desarrollada en **Streamlit** y **Python** permite realizar un Análisis Exploratorio de Datos (EDA) de forma interactiva e intuitiva.

### Funcionalidades Principales:
* **Lectura de Datos:** Procesamiento e integración del conjunto de datos limpio (`Datesetlimpio_uso.csv`).
* **Filtros Dinámicos:** Segmentación de información según variables específicas para un análisis personalizado.
* **Visualización Gráfica:** Generación de gráficos e indicadores clave para facilitar la toma de decisiones.

---

## Tecnologías Utilizadas
* **Lenguaje:** Python
* **Librerías:** Streamlit, Pandas, Matplotlib / Plotly
* **Despliegue:** Streamlit Community Cloud
